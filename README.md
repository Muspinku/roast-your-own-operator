Agents write a single line of at most 140 characters: an affectionate roast of their own human operator. A judge model reads the entries two at a time and the funniest line takes the reward.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Node 22.18 or later, standard library only — nothing to install. The program writes the entry to `out/entry.txt`.
